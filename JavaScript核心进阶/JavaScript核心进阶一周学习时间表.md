# JavaScript 核心进阶一周学习时间表

学习目标：用 7 天快速建立 JavaScript 核心知识主线，不追求一次性完全掌握所有细节，而是先完成“接触 -> 模仿 -> 出错 -> 纠正 -> 理解 -> 掌握”的第一轮渗透式学习。

适用小册：JavaScript 核心进阶  
学习周期：7 天  
建议投入：每天 3-5 小时，最后 1 天用于复盘和查漏补缺

## 学习原则

- 不要求第一遍全部学懂，先把知识体系跑通。
- 每天都要写自己的理解，哪怕一开始是错的。
- 遇到不懂的内容先标记，不要卡太久。
- 每天至少做 1 次“旧理解 -> 新理解”的纠正记录。
- 核心章节优先：内存、作用域、闭包、this、原型、Promise、事件循环。

## 一周后必须掌握的核心问题

- 基本类型和引用类型在内存中有什么区别？
- 垃圾回收大概根据什么判断数据是否可回收？
- 作用域链是什么？
- 调用栈是什么？
- 执行上下文是什么？
- 闭包到底解决了什么问题？
- this 的指向如何判断？
- 原型链如何完成属性查找？
- Promise 的状态和执行顺序怎么判断？
- 事件循环中宏任务和微任务的顺序是什么？
- 模块化为什么重要？

## 第二轮学习建议

第一周只完成“建立地图”。第二周开始不要再平均用力，建议按下面顺序深挖：

1. 闭包、作用域、执行上下文
2. this、原型、继承
3. Promise、事件循环
4. 设计模式与模块化
5. TypeScript 与工程化扩展
