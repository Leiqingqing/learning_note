# React 基础专栏 21 天学习日计划

学习目标：围绕 `React/base` 建立一轮可持续的 React 基础补强路径。你已经有一定 React 开发经验，所以本计划不把重点放在“认识 API”，而是放在“修正旧理解、补稳判断标准、把基础重新用起来”。

适用专栏：[React 18 基础版 - usehook](https://reactzm.usehook.cn/)  
学习周期：21 天  
建议投入：每天 1.5-2.5 小时  
核心方法：接触 -> 模仿 -> 出错 -> 纠正 -> 理解 -> 掌握

## 每日固定流程

- 10 分钟：回顾昨天的 1 个模糊点。
- 40-60 分钟：学习当天章节，先抓“为什么存在”，再看具体写法。
- 40-60 分钟：跟着案例做一遍，允许先模仿。
- 20 分钟：用自己的话写今日总结。
- 10 分钟：记录 1 条“旧理解 -> 新理解”的纠正。

## 每日记录模板

```md
## 第 X 天记录

今天学习：

我原来的理解：

今天修正后的理解：

我还模糊的地方：

明天优先解决：
```

## 每周复盘问题

每 7 天做一次复盘，不要求答案完美，重点是看到自己的理解变化。

- 我这一周最大的旧理解是什么？
- 哪个概念我只是会用，但还说不清楚？
- 哪个案例让我发现自己以前的写法不稳？
- 下周我应该少看一点什么，多练一点什么？



## 第一轮结束后的判断标准

完成 21 天后，如果你能回答下面这些问题，说明 React 基础已经开始变稳：

- 为什么 React 强调数据驱动视图？
- 组件拆分的依据是什么？
- props、state、ref、context 分别解决什么问题？
- useEffect 到底适合处理什么？
- 为什么会出现闭包陷阱？
- 组件为什么会重新渲染？
- memo、useCallback、useMemo 什么时候值得使用？

不要要求自己第一轮全部掌握。第一轮的目标是把知识重新接触一遍，把错误理解暴露出来。后面每一次项目实践，都是继续修正它们的机会。
